# Birmingham AI Community Impact Lab — 2026

Team project for the Community Impact Lab hack-a-thon hosted by Birmingham AI, sponsored by Anthropic. The goal: build a practical, working solution to a real Birmingham community problem in a short timeframe — not a research project, not a reinvented wheel.

## Status

**Problem not yet selected.** See [`docs/problem-statement.md`](docs/problem-statement.md) — that's the first thing the team fills in together.

## Repo structure

- `docs/problem-statement.md` — the problem we're solving, who it affects, and why (fill this in first)
- `docs/decisions.md` — running log of key decisions made during the event, with dates and reasoning
- `docs/team.md` — team members, roles, and contact info
- Everything else (app code, scripts, etc.) gets added once the problem and approach are locked in
